# AdmobLibrary

Public binary distribution for CocoaPods. This repository does not contain Swift source.

## Installation

### Option 1: Install from CocoaPods

```ruby
pod 'AdmobLibrary', '1.1.0'
```

### Option 2: Install directly from GitHub

Add the following to your `Podfile`:

```ruby
pod 'AdmobLibrary',
    :git => 'https://github.com/TienNguyen267/AdmobLibraryBinary.git',
    :tag => '1.1.0'
```

Then run:

```bash
pod install
```
